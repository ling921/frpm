# 商店更新日志

每个版本新增一个 UTF-8 JSON 文件，例如 `0.1.3.json`。文件名使用三段版本号，与 Action 的 version 输入一致。

JSON 将商店语言代码映射到纯文本更新说明，例如 `zh-cn`、`en-us`。每种语言的说明必须非空且不超过 1500 字符；必须提供 `en-us`，作为未单独翻译的商店语言的回退。

Action 从所选源码提交读取此文件，随安装包保存到 artifact。自动提交先上传包并保留草稿，再读取已有商店 listing，将对应语言的 ReleaseNotes 写入，最后提交认证。不会创建新语言或覆盖其他商品说明字段。
